# Archived prototypes

`prototype/` preserves the earlier self-built runtime, experiments, tests and demo
scripts for design reference. Nothing here is part of the active Forge Agent build,
test suite, package, supported product, or claimed functionality.

The active product uses Pi Coding Agent 1.4.0 through `src/pi-cli.ts` and
`src/web/server.ts`. Product-owned orchestration lives in `src/task/`, and
verification in `src/verification/pi-extension.ts` and `verify.ts`.

Archived imports and dependencies may no longer resolve. Do not silently enable
these modules or count their old test names as evidence for the active product.
