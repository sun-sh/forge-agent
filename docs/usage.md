# Forge Agent 使用指南

[English](usage.en.md) · [返回项目介绍](../README.md)

安装与首次配置见 [快速启动](../README.md#快速启动)，项目检查见 [配置验证](../README.md#配置验证与保护路径)。以下是界面、命令和本机数据的详细说明。

## 工作模式与执行流程

工作模式控制本轮允许使用的工具：

| 模式 | 用途 | 工具范围 |
| --- | --- | --- |
| **Agent** | 实现修改、运行命令与项目验证 | 按 Pi 配置和项目信任启用工具 |
| **Plan** | 阅读项目并制定计划 | 内置读取、搜索、公共网页和同项目会话读取工具 |
| **Ask** | 理解代码、解释实现与回答问题 | 内置读取、搜索、公共网页和同项目会话读取工具 |

Plan 和 Ask 会限制实际工具调用，阻止 shell、写入、MCP/自定义工具、扩展/技能/模板命令分派和自动验证。查看上下文、选择模型、打开设置等本地界面命令仍可使用。模式随会话保存；运行中可以选择下一条消息使用的模式，当前回合权限不会改变。它们限制模型驱动的操作；可信扩展代码仍以启动者权限运行。

Agent 模式下可以选择两种执行流程：

- **自适应（默认）**：使用 Pi 的交互循环完成日常问答和修改，由模型决定所需步骤，并执行已配置的验证。
- **规划并执行（手动启用）**：由 Forge Agent 的任务控制器推进以下阶段，每次模型与工具执行仍交给 Pi。

工具栏平时只显示 **Agent**，执行策略收在 Agent 旁默认折叠的小箭头中；手动开启后显示小型“规划”标记。选择随当前会话保存，恢复历史时保留；新对话总是从自适应开始，不继承其他会话的规划偏好。Web 发送消息时会显式带上所选策略，API 省略 `workflow` 时默认自适应。规划流程先通过只读调研形成结构化任务理解，再选择实现、回答、验证或澄清路径；正则意图提示只用于遥测。明确的宿主验证操作直接调用验证门禁。

```mermaid
flowchart LR
    Inspect[调研] --> Plan[规划]
    Plan --> Implement[实现]
    Implement --> Verify[验证]
    Verify --> Review[审阅]
    Review --> Complete[完成]
```

规划调研会保存结构化目标、约束、相关文件、未解决问题与验收条目，由宿主分配 `A1…` 编号。未识别的自然表达先做只读任务理解；不能确定就等待澄清，不能只调研便声称实现完成。调研可以在同一交接中产出有界 steps，宿主直接派生计划；只有缺少步骤时才补独立规划调用。两条路径都保留原有约束和验收；格式错误会在同一会话中校正一次，仍无效才停下。常规可逆的默认选项（例如空网页项目使用 index.html）会先复核，临时只读工具不应被视为用户阻塞。真正影响范围或核心需求的歧义仍会等待澄清。模型理解是参考，工具权限仍由模式和信任决定。

未配置自动验证时，实现结束明确标记未验证、未审阅。模型主动调用 `run_verification` 也会返回 `skipped`，不留下 `passed=false` 的空报告；宿主随后使用相同状态完成收尾，避免“文件已写完、任务却卡在 verify”的误停。已经存在的审阅阻断项不会因为移除 verify 配置而消失；保护异常、预算中止和收尾失败仍保留失败状态。

界面的“配置检查通过”仅指配置命令在当前版本的结果。语法检查、单元测试、逐项模型审阅和外部验收是不同证据：自适应实现结束且未审阅时显示“需求未独立审阅”，规划任务另列“独立模型审阅通过”。Forge 不从命令名称猜测需求覆盖率，也不把模型审阅当作外部判题。交付卡依据当前验证记录而非历史 `validation` 标记，保护异常和过期证据不能显示通过。

有验证配置时，“规划并执行”的完成门禁要求：配置的验证通过、工作区版本证据有效、保护路径保持原样、结构化审阅为 `ready` 且无未解决问题，全部验收 ID 恰好有一条带依据的确认。遗漏、重复、未确认都不能算完成。阻断缺陷记录在 `issues`；可选改进放入非阻断的 `notes`。验证失败与审阅中的具体阻断缺陷共享 `verifyRetries` 次修复机会，每次修复后重新验证和审阅。审阅 JSON 格式无效时，宿主在同一个独立 reviewer Pi 会话中只校正一次，仍计入父任务预算；第二次无效才进入待处理状态。该校正不重新执行实现流程，也不消耗或重置代码修复次数。

审阅先检查一份完整要求账本和补丁，只有缺少具体依赖时再读取项目。修复后的新 reviewer 还会收到前次阻断问题以聚焦复查，但仍须确认全部原验收项。

审阅交接包含实际 staged / unstaged / untracked 文本补丁，保留已有用户变更的标记。每文件最多 2,000 行、补丁合计最多 60,000 字符；补丁过大、二进制、敏感路径、Git 清单被截断或 HEAD 已改变时停止并提示人工检查。请使用 Git 仓库根目录以获得完整审阅证据。补丁只写入 reviewer 的本地 Pi 会话，不随每条任务计数快照重复持久化。

### 保护测试、锁文件或其他项目路径

在项目的 `forge-agent.json` 中配置，例如：

```json
{
  "verify": [{ "name": "test", "command": "npm test" }],
  "verifyRetries": 2,
  "protect": ["tests", "package-lock.json"]
}
```

`protect` 接受字面相对文件或目录，不支持 glob、绝对路径、父目录穿越、链接或 `.git`。目录递归包含被忽略的普通文件。每轮模型执行前记录内容指纹，所有自动修复都沿用该基线：执行前已有的用户修改允许存在，但执行中不得变化；原本不存在的保护路径也不得创建。校验命令通过仍可能因保护路径变化而失败，路径列表会反馈模型，并同时影响 Web 完成状态和 CLI 退出码。恢复原始内容后必须重新验证。

最多配置 200 个路径；单次观察最多 20,000 个目录项、256 MiB、20 秒。超限或不可读取会阻止完成。保护是宿主的交付检查，不能阻止工具造成副作用，也不是操作系统沙箱；执行中修改后又完全恢复的瞬时行为不在指纹证明范围内。未配置 `verify` 时，保护检查也会执行，但不会显示“自动验证通过”。

点击进度条旁的**执行记录**，或右侧工作区的**执行**标签，查看目标与验收、审阅、阶段、模型 token、工具结果、检查和重复实现尝试。记录默认按阶段折叠，不挤占主对话。工具时长按消息间隔估算，包含等待；调用没有结果时保持中断或进行中，不推定成功。会话重开后记录可重新生成；这里没有重新执行副作用的按钮。协议与限制见[执行记录](execution-records.md)。

模型阶段结束后仍需完成检查点封存、模式恢复与保存确认。此时显示收尾中；任何收尾异常都会使任务失败，历史验证通过记录仍保留。运行状态、任务中心、队列和恢复后的结果使用相同终态。永久存储故障会明确报告，无法承诺失败记录已经落盘。

自适应流程不会自动增加模型审阅阶段，界面分别显示执行、验证和审阅结果。验证绑定检查命令配置与工作区内容指纹；撤销、应用子任务补丁和项目终端操作会立即使旧证据失效，包括部分失败的操作。打开会话或任务、重连、重启恢复时会复核外部改动，空闲查询最多复用 1.5 秒内的观察结果。原始报告保留为历史记录，不会变成当前版本的通过证据。

指纹覆盖 Git 的已跟踪文件、未忽略的新文件、HEAD 和暂存区；非 Git 项目覆盖普通文件。凭据文件、`node_modules` 和 Forge 本地状态不在范围内。观察最多 20,000 项、256 MiB 和 20 秒；链接、嵌套仓库、不可读或超限内容显示版本未确认。验证期间覆盖范围内的文件有变化也不能确认版本；构建输出应正确加入忽略规则。它是有界的内容观察，不是原子文件系统快照、环境证明或 OS 沙箱。

停止任务会阻止后续阶段。服务重启后，未完成任务显示为中断，需要明确继续。聊天框和任务中心均保留原任务的执行策略，不受下一条消息的策略偏好影响：自适应任务通过 Pi 继续，规划任务复用已保存的目标、约束和计划，从中断阶段继续；verify/review 中断后先重新验证当前版本。旧记录缺少有效交接时才重新调研。保护基线与已用修复次数跨继续保留。继续会在原 Pi 会话中发送隐藏的宿主续接消息，复用当前工作区，不重复追加原始用户请求，也不重放旧工具调用。独立模型审阅仍可能遗漏问题。

任务卡默认折叠为一行。暂停原因会在聊天框上方显示，详细步骤和预算按需展开；阶段状态与预算用量分别展示。

模型、推理强度、工作模式和执行策略可以在运行中选择；此时显示“下次”标记，选择仅在下一条消息发送前应用，当前回合的模型与权限保持不变。运行中可以从左侧切换会话或新建对话，原任务继续在服务端运行；每个会话保留自己的草稿、页内附件和暂存选择。全局服务配置、当前项目绑定和当前会话历史修改仍需等待相应任务空闲。切换页面不会解除同项目的执行锁；同一真实项目仍独占执行，其他项目可独立执行。思考、工具调用和阶段性输出默认收进“执行过程”，最终回答单独显示；输入框使用 `Enter` 发送，`Shift+Enter` 换行。

终端工具也有独立的命令超时：Pi 内置 bash / powershell 没有传 timeout 时默认 120 秒，模型可为长构建和测试显式指定更长时间；已有显式超时保持不变。超时由 Pi 终止子进程树，并把失败返回模型，模型可以调整命令继续；这不会自动用尽整段任务预算。

单次回复的最大输出与整段任务预算不同。模型返回 `length`（包括只有思考、没有正文/工具调用）或空结果时，Web 在 Pi 结束边界最多自动续接两次；模型/思考档位不变，用量仍计入当前预算。再次失败会停在原阶段，显示截断或空输出原因，不进入验证。旧记录若已错误推进到 verify，点击继续会回到未完成的实现。模型应先创建最小可运行文件，再分块编辑，避免在一条回复里规划完整源码。

### 执行预算与项目占用

打开 **设置 → 关于 → 执行预算** 可以设置每次执行的总时长、模型回合、工具调用、生成 token、累计请求 token 和费用上限。新安装的默认值为 90 分钟、240 个模型回合、500 次工具调用、300,000 个生成 token、累计请求 token 为 0（关闭）和 40 美元；已有保存配置保留原值。“长任务 · 4 小时”预设填入 400 回合、800 次工具调用和 500,000 生成 token，保留当前费用上限，保存后才生效。自适应和规划并执行都使用这套预算；规划、验证修复和独立交付审阅共享当前执行段预算。达到上限后任务状态变为 **达到执行预算**，Pi 会收到中止信号；点击聊天框中的继续会保留当前会话和工作区，开始新的有界执行段，不重复发送原始请求。也可以调整预算后重新检查。

累计请求 token（如果设置了大于 0 的上限）包含多轮重复上下文与缓存读取，和输入框下面的当前上下文窗口占用不同。执行详情分别列出新输入、输出、缓存读取和缓存写入；中止后仍会记录已在途响应的用量。服务未配置有效价格时显示费用未知，混合执行显示已知部分与未知提示，不能把它解释为免费或据此保证费用上限。默认的硬 token 保护是生成 token 上限。

Provider 的 token 和费用通常在一轮响应结束时才会报告，因此预算是宿主侧的保护阈值，单轮响应可能略微超过设置值，不能当作账单级隔离。预算文件保存在 `FORGE_AGENT_HOME/web-settings.json`，不会写入项目的严格 `forge-agent.json`。

同一个 `FORGE_AGENT_HOME` 同时只允许一个 Web 服务。异常退出后租约可在 stale 时间后恢复；第二个实例显示已有服务地址。Agent、终端、Trust 变更及受审阅文件操作共享项目占用，目录别名按真实路径归一化。关闭服务取消活跃终端并等待释放。独立后台进程与持久化队列可处理后续任务，已中断执行仍需明确重试。

## 项目、会话与附件

项目右侧的 `…` 菜单可以**移除项目**。本机源码和 Pi 会话文件会保留，刷新页面或重启服务后仍保持移除状态；重新打开原文件夹即可恢复项目及其历史。项目正在执行任务时，需要先停止任务。

拖动输入框顶部的细横条可以上下调整高度，浏览器会记住你的选择，并按可用屏幕空间限制最大高度。双击横条恢复默认；聚焦横条后也可使用方向键调整、Home/End 设为最小/最大。输入或清空文字不会改变你选择的高度。

首次打开 Web 客户端时不会预选服务启动目录。你可以直接输入消息；在模型可用后，Forge 会按消息标题在 `FORGE_AGENT_HOME/projects` 下创建一个独立项目目录，并把当前会话绑定到那里。项目选择器还支持显式创建 Forge 管理的项目、打开电脑上的其他文件夹，或回到“发送时自动创建”。外部文件夹保留在原位置，Forge 只登记规范化路径；同一项目的会话仍统一写入 `FORGE_AGENT_HOME/sessions`。

发送按钮旁的回形针图标支持多选图片与文件，也支持拖放和粘贴图片。图片支持 PNG、JPEG、WEBP 和 GIF；本机文件支持 UTF-8 文本与代码，内容以内联材料发送给模型，不会自动写入项目目录。项目文件引用需要先选择项目，敏感凭据、符号链接、二进制文件和超出大小上限的内容会被拒绝。上传内容被标记为用户材料，不能改变 Agent 的工具权限或项目策略。

## 子任务

复杂请求可要求“并行探索这两个模块”“独立审阅风险”或“在独立工作目录提出实现”。主 Agent 也可按需委派；简单问题无需走子任务。委派可以同时给出文件范围、预期产物、验收条件和依赖，帮助父任务判断子结果，但不会改变权限。探索和审阅只读，实现使用隔离 worktree 的编辑工具；均不执行 shell，继承委派时父任务模型及推理强度。

有子任务时，标题旁出现子任务人数图标。点击查看标题、状态、耗时与 token，选中后在右侧查看子会话。任务说明、工具和思考默认折叠；**停止子任务**只停止当前孩子，聊天框的停止按钮会停止整个父任务与所有孩子。关闭详情后返回原对话。需要追问可告诉主 Agent“继续刚才的审阅子任务，重点检查……”，主 Agent 使用原子任务 ID 续问；当前子面板不提供单独聊天输入。

子会话不出现在普通历史列表。刷新保留记录，中断后不会自动重跑。父预算与子预算同时生效；多个实现子任务各用独立 worktree，用户逐个审阅应用，冲突不自动合并。可写任务需新建委派，不能续用旧 worktree 重放。

## 联网与基本工具

Forge 在 Pi 扩展机制中注册 `web_search` 和 `web_fetch`，Web 与终端入口均可使用。网页搜索通过公共搜索页获取标题、摘要与网址（Yahoo 优先，DuckDuckGo / Bing 备用），不需要另存 API Key；公共站点仍可能限流、返回验证码或改变格式，此时工具返回真实错误，不编造搜索结果。可以继续读取已知官方文档地址，或通过 MCP 连接自己的搜索服务。

在 **设置 → 工具** 中开关联网并点击“测试文档连接”，会实际读取 Three.js 官方文档；检测文档连接不代表所有搜索服务都畅通。配置保存在 Forge 数据目录的 `network.json`，不写入项目的严格配置。运行任务时不能切换该配置；空闲会话重载后生效，禁用状态下工具隐藏且执行入口也拒绝调用。

Plan / Ask 与 planned inspect 可以使用宿主只读联网工具；同名项目自定义工具不会借此获得权限。独立 reviewer 和 worker 保持其已有工具范围。终端命令、npm 依赖安装、浏览器 MCP 与网页读取是不同能力；模型不能因为某个 CDN 请求失败就断言无法联网或无法使用 Three.js。

网页读取使用 Mozilla Readability 与 LinkeDOM 提取正文，不执行脚本，不使用浏览器登录或 Cookie。每次请求链总时限 20 秒、最多 4 次重定向、响应最多 2 MB，正文默认 24,000 字符、最高 60,000 字符并明确标注截断。仅接受公共 HTTP(S) 地址和 80/443 端口；每次重定向重新检查 DNS 并绑定已校验 IP，拒绝本机、内网和保留地址。网页文本带不可信数据标记，不能更改工具权限。JS 渲染、登录与交互请连接浏览器 MCP。联网开关不限制终端、MCP 或扩展的系统网络权限。

## 输入区命令与上下文

在输入框中输入 `/`，或点击输入框下方的 **命令**，可以搜索并选择操作。使用 `↑` / `↓` 选择，`Enter` 执行，`Tab` 补全，`Esc` 关闭。

| 命令 | 用途 |
| --- | --- |
| `/new`、`/rename` | 新建对话、重命名当前对话 |
| `/model`、`/mode` | 打开模型与推理强度选择、工作模式选择 |
| `/context` | 查看当前上下文估算、容量、累计用量和自动压缩状态 |
| `/compact [保留重点]` | 手动压缩较早内容，可附加摘要需要保留的重点 |
| `/changes` | 打开右侧代码变更面板 |
| `/queue [任务内容]` | 将后续文本任务持久化排队；无参数打开任务中心 |
| `/mcp`、`/settings`、`/help` | 打开 MCP 设置、通用设置、命令与快捷键帮助 |

菜单按“操作、技能、模板”分类，扩展命令在加载后显示。“切换模型”（`/model`）与“工作模式”（`/mode`）用中文标题区分，完整输入时只显示精确匹配项。点击“技能”可加载当前项目的技能列表；具体技能选择后补全为 `/skill:名称`，可以附加任务再发送。浏览列表和选择技能不请求模型，实际执行由 Pi 处理。模型也可以按需读取适用技能。不可用的操作会说明原因，未知命令保留在输入框中供修改。运行中选择模型和推理强度仍对下一条消息生效。

上下文占用和 **压缩** 按钮常驻输入框下方。点击上下文可以展开累计输入/输出、缓存、目录估算费用和压缩次数；累计用量与当前窗口占用分别显示。手动压缩会调用当前模型，在会话空闲时可用，支持取消。历史记录会保留；压缩后暂不展示旧占用数值，等待下一次模型回复更新。

打开 **设置 → 记忆** 可以维护三层参考资料：全局记忆跨项目复用，项目记忆只注入当前文件夹，会话记忆保存在 Pi 会话树中并随分支保留。每条记忆可以标记为事实、偏好、决定或约束，也可以单独停用。记忆内容只作为用户参考资料注入，不会获得工具权限。自动压缩开关和 Pi 的 `reserveTokens`、`keepRecentTokens` 会在同一页显示；原始历史不会因压缩而丢失。

## 管理技能

打开 **设置 → 技能**，或在 `/` 菜单的“技能”分类点击 **管理技能**。可按名称、描述、来源搜索，按全局或当前项目筛选，查看技能指令、加载诊断，以及“可自动调用 / 仅手动调用 / 已停用 / 同名覆盖”等状态。

展开 **添加本机技能**，填写包含 `SKILL.md` 的目录或已有 Markdown 技能文件，选择全局或当前项目后导入。额外路径可以移除引用，本机文件会保留；自动发现目录中的技能可通过开关停用。项目资源仍需要项目信任。保存或刷新会重新加载空闲会话，`/` 菜单随之更新，无需重启服务。

发现、同名优先级、启停过滤和配置持久化使用 Pi 原生机制。浏览列表与预览内容不请求模型，也不会为管理页加载项目扩展或自动安装缺失资源包。

## 连接 MCP 服务

打开 **设置 → MCP → 添加**，选择本机 STDIO 或 Streamable HTTP，填写命令与参数，或 URL 与 Headers。也可以展开 **从 JSON 导入配置**，粘贴其他客户端使用的 `mcpServers` JSON，选择一个服务填入表单。命令参数每行填写一个，包含空格的路径保持在同一行。

先点击 **测试当前配置**，查看连接结果与可用的工具目录，再保存。若 HTTP 服务提示需要 OAuth，保存后点击 **登录授权**；浏览器批准后自动完成回调。弹窗被拦截时可以点击授权链接，也支持手动提交回调、取消和移除本机授权。MCP 授权与模型服务的 Provider 登录分别管理。

- **全局与项目**：全局配置保存在 `FORGE_AGENT_HOME/mcp.json`，项目配置保存在 `<project>/.pi/mcp.json`。项目配置仅在项目信任后加载。同名项目条目可以替换全局服务，也可以只覆盖启用状态和工具暴露方式，后者不会把全局凭据复制到项目。
- **连接测试**：使用临时 Pi 会话建立真实连接，显示最近结果和发现的工具；不请求模型，也不调用工具。测试会启动服务进程，结束后回收连接。该结果不代表每个聊天会话的实时连接状态。
- **配置生效**：保存、启停和删除会通过 Pi 重新加载受影响的空闲会话。任务运行时需要先停止，再修改配置；会话保留原有工作模式限制。
- **工具设置**：逐项设置工具的提供方式，也可以添加通配规则或恢复继承；已有 `toolExposure` 规则会保留。精确工具名优先于通配规则，多个通配规则按配置顺序匹配。Plan / Ask 始终阻止 MCP 工具执行。
- **会话连接状态**：展开后查看当前项目各会话实际加载的服务，每 3 秒更新连接状态与工具数量，并支持空闲会话重连。
- **凭据与编辑**：环境变量、Header 值和 OAuth Client Secret 保存后不会回显；留空保留已有值，移除对应行或勾选删除后清除。多窗口修改会检查冲突，OAuth 完成与状态刷新会保留正在编辑的草稿。

在服务卡片中打开 **工具设置**，按使用场景选择：

| 方式 | 适用场景与行为 |
| --- | --- |
| **Codemode**（默认） | Agent 通过脚本发现并组合调用工具，适合需要组合或筛选结果的任务。 |
| **Deferred** | 按需搜索后再向模型提供工具，适合工具较多的服务。 |
| **Direct** | 直接向模型提供工具，也可以从脚本调用，适合少量常用工具。 |
| **Hidden** | 隐藏工具，使其不可调用。 |

MCP 协议、传输、工具发现、执行和 OAuth 仍使用 Pi。网页授权完成后更新空闲会话；运行中的会话会在本轮结束后更新。凭据应放在环境变量、Headers 或 OAuth Secret 字段，避免直接写进命令参数或 URL；修改连接目标时需要重新填写保留的凭据。外部厂商的 OAuth 元数据、注册方式与代理环境仍需要实际兼容验收。详见 [MCP 管理设计](mcp-management.md)。

## 审阅记忆、变更和子任务

模型通过 `memory_proposal` 提出的项目/会话事实会出现在 **设置 → 记忆 → 待审阅记忆**。候选不自动进入上下文；核对内容和来源说明后接受，或拒绝。相同内容会提示重复，替换项会展示原记忆；其他窗口改动后需要重新审阅。来源说明由模型提供，不是外部事实认证。手工记忆仍可编辑、禁用和删除。

右侧 **变更 → 执行检查点** 可选择一次 Agent 执行、查看文件差异，勾选后撤销。只有可信 Git 仓库根目录可建立检查点，忽略/已知敏感/链接/超限文件不在范围内。恢复保留执行前的未提交内容，不重置 Git；HEAD/暂存区变化或之后的文件编辑会阻止撤销。逐文件恢复中断后需人工检查，不能当作项目备份。

子任务列表中的“实现”使用独立 worktree，探索和审阅仍只读。打开实现任务，审阅 proposal 并选择文件，可以单独应用，或“应用并验证”运行主项目已配置的检查；缺少验证配置时会先提示。验证失败保留变更和输出，不自动撤销。不会自动合并冲突；清理工作目录保留封存 proposal。子任务没有 shell、MCP 或继续委派权限。见 [子任务设计](subagents.md)。

## 后台和排队

先完成会话第一轮，再在任务中心添加任务，或通过 `/queue 任务内容` 排队。最多 3 个不同项目并行，同一项目和会话按顺序执行；忙碌项目不阻塞其他项目。任务中心展示运行数和等待原因，可独立停止运行项或取消排队项。失败/中断项可以明确“重新排队”，创建新执行并先检查当前状态。排队时固定模型、推理强度和流程，附件不会自动带入。界面只显示已经落盘的队列状态。详见 [多任务与进度](task-scheduling.md)。

`npm start` 的前台进程关闭后不会继续工作。需要后台时，先停止前台，再执行 `node dist/pi-cli.js service start`；`service status` 查看状态，`service stop` 停止并保留未开始任务。已开始但中断的任务不会自动重放。详见 [运行、存储与升级](operations.md)。

## 其他入口

需要命令行时，在源码目录执行一次 `npm link`：

```bash
forge-agent web                            # 启动 Web 客户端
forge-agent                                # Pi 提供的交互式终端界面
forge-agent doctor                         # 检查本机配置，不显示凭据值
forge-agent check                          # 执行当前项目配置的验证
forge-agent -C path/to/project -p "Fix the failing tests"
```

Web 中的 API Key 配置覆盖常用兼容服务，MCP 有独立的设置入口。模型服务的 OAuth 登录仍使用终端中的 `/login`；Skills 和扩展的高级配置由 Pi 管理，Web 使用同一份本机配置。

历史会话保存在 `FORGE_AGENT_HOME/sessions`。侧栏按项目分组，菜单操作直接写入 Pi 会话的元数据；归档和回收站只改变 Web 展示状态，原始会话文件仍可恢复。分支会生成新的 Pi 会话文件，并记录来源会话；建立分支不会自动发送模型请求，编辑用户消息的分支会把文本放回输入框。

## 本机数据与安全

| 内容 | 默认位置 |
| --- | --- |
| 配置、模型与认证 | `~/.forge-agent`，可通过 `FORGE_AGENT_HOME` 指定 |
| Forge 管理的项目 | `FORGE_AGENT_HOME/projects` |
| 项目索引 | `FORGE_AGENT_HOME/web/projects.json` |
| 全局 MCP 配置与 OAuth 凭据 | `FORGE_AGENT_HOME/mcp.json` 与 `FORGE_AGENT_HOME/mcp-auth.json` |
| 项目 MCP 配置 | `<project>/.pi/mcp.json`，仅在项目信任后加载 |
| 会话 | `FORGE_AGENT_HOME/sessions` |
| 全局与项目记忆 | `FORGE_AGENT_HOME/memory`；项目文件使用规范化真实目录身份，旧文件在作用域验证后迁移；会话记忆写入 Pi 会话树 |
| Web 设置、执行预算与任务索引 | `FORGE_AGENT_HOME/web-settings.json`、`FORGE_AGENT_HOME/tasks` |
| 验证证据与原始输出 | `FORGE_AGENT_HOME/verification` |
| 队列、检查点和可写子任务目录 | `FORGE_AGENT_HOME/tasks/queue.json`、`checkpoints/`、`worktrees/` |
| 本机网关访问凭证 | `FORGE_AGENT_HOME/web/access-token` |

旧的 `PFORGE_HOME`、`~/.pforge` 与 `pforge.json/yaml/yml` 保持兼容；同目录中新的 `forge-agent.*` 配置优先。已有会话继续使用兼容的存储标识。

Web 网关默认绑定 `127.0.0.1`，使用本机访问凭证和 HttpOnly、SameSite=Strict Cookie，并检查 Host 与 Origin。模型 API Key 通过 Pi 认证接口保存，不会返回编辑器或写入浏览器存储。

“本机运行”指客户端、进程和数据存储的位置。使用远程模型时，相关内容仍会发送到你配置的服务。Agent、可信扩展与验证命令拥有启动者的操作系统权限，项目信任不构成 OS 沙箱；不可信项目请使用容器、虚拟机或受限账号。会话和原始日志可能含敏感内容，分享前需要检查。详见 [安全说明](../SECURITY.md)。

## 会话上下文与同项目引用

每个对话使用独立的 Pi SessionManager、消息分支、压缩摘要和任务状态。设置中已接受的全局/项目参考记忆可按作用域复用；它与共享完整聊天记录是两件事。切换会话不会把另一个会话的消息自动注入。

可以直接要求“参考本项目之前讨论配色的会话”。Web Agent 会按需调用 `search_project_conversations` 查找标题或关键词，再用 `read_project_conversation` 读取分段文本，并标明来源会话 ID 和条目 ID。空查询只返回会话标题元数据；历史用户/助手正文与保留的压缩摘要可读，思考、工具输出和隐藏宿主指令不返回。已归档会话可引用，回收站、其他项目、私有 worker/reviewer 目录不可由这两个工具读取。Plan/Ask 也允许宿主提供的这两个只读工具；同名的任意扩展不获得读取工具白名单。

每次按需扫描最多 2,000 个根目录会话文件、单文件 8 MB、总读取 64 MB，超限/损坏会明确标记检索不完整。读取每次默认 12,000 字符、上限 24,000；分页带来源 revision，运行中的来源发生变化后需重新读取。它是历史参考，不能授予工具权限或充当当前验证证据。这是 Forge 工具的访问范围，不是对 Pi shell 或宿主文件系统的 OS 隔离。
