# Forge Agent 使用指南

[English](usage.en.md) · [返回项目介绍](../README.md)

安装与首次配置见 [快速启动](../README.md#快速启动)，项目检查见 [配置验证](../README.md#配置验证)。以下是界面、命令和本机数据的详细说明。

## 工作模式与执行流程

工作模式控制本轮允许使用的工具：

| 模式 | 用途 | 工具范围 |
| --- | --- | --- |
| **Agent** | 实现修改、运行命令与项目验证 | 按 Pi 配置和项目信任启用工具 |
| **Plan** | 阅读项目并制定计划 | 仅内置读取、搜索工具 |
| **Ask** | 理解代码、解释实现与回答问题 | 仅内置读取、搜索工具 |

Plan 和 Ask 会限制实际工具调用，阻止 shell、写入、MCP/自定义工具、扩展/技能/模板命令分派和自动验证。查看上下文、选择模型、打开设置等本地界面命令仍可使用。模式随会话保存，运行期间不能切换。它们限制模型驱动的操作；可信扩展代码仍以启动者权限运行。

Agent 模式下可以选择两种执行流程：

- **自适应（默认）**：使用 Pi 的交互循环完成日常问答和修改，由模型决定所需步骤，并执行已配置的验证。
- **规划并执行（手动启用）**：由 Forge Agent 的任务控制器推进以下阶段，每次模型与工具执行仍交给 Pi。

工具栏平时只显示 **Agent**，执行策略收在 Agent 旁默认折叠的小箭头中；手动开启后显示小型“规划”标记。选择随当前会话保存，恢复历史时保留；新对话总是从自适应开始，不继承其他会话的规划偏好。Web 发送消息时会显式带上所选策略，API 省略 `workflow` 时默认自适应。规划流程还会根据请求类型分流：能力询问和只读分析只进行一次受限的读取回合，明确的验证请求直接运行验证门禁，需要改代码的请求才进入完整阶段流程。

```mermaid
flowchart LR
    Inspect[调研] --> Plan[规划]
    Plan --> Implement[实现]
    Implement --> Verify[验证]
    Verify --> Review[审阅]
    Review --> Complete[完成]
```

“规划并执行”的完成门禁要求：配置的验证通过、结构化审阅为 `ready` 且没有未解决问题，在可用的 Git 证据范围内未检测到审阅期间的变更。验证失败最多自动修复 `verifyRetries` 次；审阅发现问题、没有配置检查、审阅无效或证据失效时，任务会进入需要处理的状态。

停止任务会阻止后续阶段。服务重启后，未完成任务显示为中断，只有点击 **重新检查并继续** 才会重新调研当前工作区。模型审阅是第二次检查，仍可能遗漏问题。

模型和推理强度可以在运行中打开选择器；此时选择会暂存，只在下一条消息发送前应用，当前回合不会被切换。执行中的项目、工作模式、执行策略、设置和新建会话入口会锁定。思考、工具调用和阶段性输出默认收进“执行过程”，最终回答单独显示；输入框使用 `Enter` 发送，`Shift+Enter` 换行。

### 执行预算与项目占用

打开 **设置 → 关于 → 执行预算** 可以设置每次执行的总时长、模型回合、工具调用、累计 token 和费用上限。默认值为 15 分钟、50 个模型回合、300 次工具调用、750,000 个 token 和 25 美元。自适应和规划并执行都使用这套预算；规划阶段、验证修复和模型审阅共享同一个累计值，内部继续不会重置它。达到上限后任务状态变为 **达到执行预算**，Pi 会收到中止信号，调整预算后可以重新检查。

Provider 的 token 和费用通常在一轮响应结束时才会报告，因此预算是宿主侧的保护阈值，单轮响应可能略微超过设置值，不能当作账单级隔离。预算文件保存在 `FORGE_AGENT_HOME/web-settings.json`，不会写入项目的严格 `forge-agent.json`。

同一个 `FORGE_AGENT_HOME` 同时只允许一个 Web 服务。服务异常退出后，租约在 stale 时间后可以恢复；第二个启动的实例会显示已有服务地址。一个项目在同一时间只允许 Agent、终端命令或 Trust 变更中的一种操作，目录 junction、符号链接和 Windows 大小写别名会按真实目录归一化。关闭服务会取消活跃终端并等待项目占用释放。当前仍没有独立后台队列，运行中的任务由本机网关持有。

## 输入区命令与上下文

在输入框中输入 `/`，或点击输入框下方的 **命令**，可以搜索并选择操作。使用 `↑` / `↓` 选择，`Enter` 执行，`Tab` 补全，`Esc` 关闭。

| 命令 | 用途 |
| --- | --- |
| `/new`、`/rename` | 新建对话、重命名当前对话 |
| `/model`、`/mode` | 打开模型与推理强度选择、工作模式选择 |
| `/context` | 查看当前上下文估算、容量、累计用量和自动压缩状态 |
| `/compact [保留重点]` | 手动压缩较早内容，可附加摘要需要保留的重点 |
| `/changes` | 打开右侧代码变更面板 |
| `/mcp`、`/settings`、`/help` | 打开 MCP 设置、通用设置、命令与快捷键帮助 |

菜单按“操作、技能、模板”分类，扩展命令在加载后显示。“切换模型”（`/model`）与“工作模式”（`/mode`）用中文标题区分，完整输入时只显示精确匹配项。点击“技能”可加载当前项目的技能列表；具体技能选择后补全为 `/skill:名称`，可以附加任务再发送。浏览列表和选择技能不请求模型，实际执行由 Pi 处理。模型也可以按需读取适用技能。不可用的操作会说明原因，未知命令保留在输入框中供修改。运行中选择模型和推理强度仍对下一条消息生效。

上下文占用和 **压缩** 按钮常驻输入框下方。点击上下文可以展开累计输入/输出、缓存、目录估算费用和压缩次数；累计用量与当前窗口占用分别显示。手动压缩会调用当前模型，在会话空闲时可用，支持取消。历史记录会保留；压缩后暂不展示旧占用数值，等待下一次模型回复更新。

打开 **设置 → 记忆** 可以维护三层参考资料：全局记忆跨项目复用，项目记忆只注入当前文件夹，会话记忆保存在 Pi 会话树中并随分支保留。每条记忆可以标记为事实、偏好、决定或约束，也可以单独停用。记忆内容只作为用户参考资料注入，不会获得工具权限。自动压缩开关和 Pi 的 `reserveTokens`、`keepRecentTokens` 会在同一页显示；原始历史不会因压缩而丢失。

## 管理技能

打开 **设置 → 技能**，或在 `/` 菜单的“技能”分类点击 **管理技能**。可按名称、描述、来源搜索，按全局或当前项目筛选，查看技能指令、加载诊断，以及“可自动调用 / 仅手动调用 / 已停用 / 同名覆盖”等状态。

展开 **添加本机技能**，填写包含 `SKILL.md` 的目录或已有 Markdown 技能文件，选择全局或当前项目后导入。额外路径可以移除引用，本机文件会保留；自动发现目录中的技能可通过开关停用。项目资源仍需要项目信任。保存或刷新会重新加载空闲会话，`/` 菜单随之更新，无需重启服务。

发现、同名优先级、启停过滤和配置持久化使用 Pi 原生机制。浏览列表与预览内容不请求模型，也不会为管理页加载项目扩展或自动安装缺失资源包。

## 连接 MCP 服务

打开 **设置 → MCP → 添加**，选择本机 STDIO 或 Streamable HTTP，填写命令与参数，或 URL 与 Headers。也可以展开 **从 JSON 导入配置**，粘贴其他客户端使用的 `mcpServers` JSON，选择一个服务填入表单。命令参数每行填写一个，包含空格的路径保持在同一行。

先点击 **测试当前配置**，查看连接结果与可用的工具目录，再保存。若 HTTP 服务提示需要 OAuth，保存后点击 **登录授权**；浏览器批准后自动完成回调。弹窗被拦截时可以点击授权链接，也支持手动提交回调、取消和移除本机授权。MCP 授权与模型服务的 Provider 登录分别管理。

- **全局与项目**：全局配置保存在 `FORGE_AGENT_HOME/mcp.json`，项目配置保存在 `<project>/.pi/mcp.json`。项目配置仅在项目信任后加载。同名项目条目可以替换全局服务，也可以只覆盖启用状态和工具暴露方式，后者不会把全局凭据复制到项目。
- **连接测试**：使用临时 Pi 会话建立真实连接，显示最近结果和发现的工具；不请求模型，也不调用工具。测试会启动服务进程，结束后回收连接。该结果不代表每个聊天会话的实时连接状态。
- **配置生效**：保存、启停和删除会通过 Pi 重新加载受影响的空闲会话。任务运行时需要先停止，再修改配置；会话保留原有工作模式限制。
- **工具设置**：逐项设置工具的提供方式，也可以添加通配规则或恢复继承；已有 `toolExposure` 规则会保留。精确工具名优先于通配规则，多个通配规则按配置顺序匹配。Plan / Ask 始终阻止 MCP 工具执行。
- **会话连接状态**：展开后查看当前项目各会话实际加载的服务，每 3 秒更新连接状态与工具数量，并支持空闲会话重连。
- **凭据与编辑**：环境变量、Header 值和 OAuth Client Secret 保存后不会回显；留空保留已有值，移除对应行或勾选删除后清除。多窗口修改会检查冲突，OAuth 完成与状态刷新会保留正在编辑的草稿。

在服务卡片中打开 **工具设置**，按使用场景选择：

| 方式 | 适用场景与行为 |
| --- | --- |
| **Codemode**（默认） | Agent 通过脚本发现并组合调用工具，适合需要组合或筛选结果的任务。 |
| **Deferred** | 按需搜索后再向模型提供工具，适合工具较多的服务。 |
| **Direct** | 直接向模型提供工具，也可以从脚本调用，适合少量常用工具。 |
| **Hidden** | 隐藏工具，使其不可调用。 |

MCP 协议、传输、工具发现、执行和 OAuth 仍使用 Pi。网页授权完成后更新空闲会话；运行中的会话会在本轮结束后更新。凭据应放在环境变量、Headers 或 OAuth Secret 字段，避免直接写进命令参数或 URL；修改连接目标时需要重新填写保留的凭据。外部厂商的 OAuth 元数据、注册方式与代理环境仍需要实际兼容验收。详见 [MCP 管理设计](mcp-management.md)。

## 其他入口

需要命令行时，在源码目录执行一次 `npm link`：

```bash
forge-agent web                            # 启动 Web 客户端
forge-agent                                # Pi 提供的交互式终端界面
forge-agent doctor                         # 检查本机配置，不显示凭据值
forge-agent check                          # 执行当前项目配置的验证
forge-agent -C path/to/project -p "Fix the failing tests"
```

Web 中的 API Key 配置覆盖常用兼容服务，MCP 有独立的设置入口。模型服务的 OAuth 登录仍使用终端中的 `/login`；Skills 和扩展的高级配置由 Pi 管理，Web 使用同一份本机配置。

历史会话保存在 `FORGE_AGENT_HOME/sessions`。侧栏按项目分组，菜单操作直接写入 Pi 会话的元数据；归档和回收站只改变 Web 展示状态，原始会话文件仍可恢复。分支会生成新的 Pi 会话文件，并记录来源会话；建立分支不会自动发送模型请求，编辑用户消息的分支会把文本放回输入框。

## 本机数据与安全

| 内容 | 默认位置 |
| --- | --- |
| 配置、模型与认证 | `~/.forge-agent`，可通过 `FORGE_AGENT_HOME` 指定 |
| 全局 MCP 配置与 OAuth 凭据 | `FORGE_AGENT_HOME/mcp.json` 与 `FORGE_AGENT_HOME/mcp-auth.json` |
| 项目 MCP 配置 | `<project>/.pi/mcp.json`，仅在项目信任后加载 |
| 会话 | `FORGE_AGENT_HOME/sessions` |
| 全局与项目记忆 | `FORGE_AGENT_HOME/memory`；项目文件使用规范化真实目录身份，旧文件在作用域验证后迁移；会话记忆写入 Pi 会话树 |
| Web 设置、执行预算与任务索引 | `FORGE_AGENT_HOME/web-settings.json`、`FORGE_AGENT_HOME/tasks` |
| 验证证据与原始输出 | `FORGE_AGENT_HOME/verification` |
| 本机网关访问凭证 | `FORGE_AGENT_HOME/web/access-token` |

旧的 `PFORGE_HOME`、`~/.pforge` 与 `pforge.json/yaml/yml` 保持兼容；同目录中新的 `forge-agent.*` 配置优先。已有会话继续使用兼容的存储标识。

Web 网关默认绑定 `127.0.0.1`，使用本机访问凭证和 HttpOnly、SameSite=Strict Cookie，并检查 Host 与 Origin。模型 API Key 通过 Pi 认证接口保存，不会返回编辑器或写入浏览器存储。

“本机运行”指客户端、进程和数据存储的位置。使用远程模型时，相关内容仍会发送到你配置的服务。Agent、可信扩展与验证命令拥有启动者的操作系统权限，项目信任不构成 OS 沙箱；不可信项目请使用容器、虚拟机或受限账号。会话和原始日志可能含敏感内容，分享前需要检查。详见 [安全说明](../SECURITY.md)。
